# ChunkFlow 下载

本仓库提供 ChunkFlow 安装包。

[下载最新版本](https://github.com/Typigit/chunkflow-releases/releases)

- Windows：下载 portable.zip，完整解压后运行 EXE，保留 DLL 和 data 文件夹。
- macOS：下载 macOS.zip，解压后使用。当前试用版未公证。
- Android：下载 test.apk。当前使用测试签名。
- iOS：unsigned.ipa 需要自行签名，不能直接安装。

服务器地址默认留空；首次打开时在设置中填写自己的 HTTPS 协调服务地址。
下载链接无需登录 GitHub。每个版本提供 SHA256SUMS.txt 用于校验安装包。
GitHub 自动生成的 Source code 压缩包仅包含本下载仓库的说明文件。
